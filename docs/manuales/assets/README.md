# Recursos de documentación

Esta carpeta guarda imágenes y notas compartidas para los manuales de HU29.

## Estructura

- `architecture/` — notas y diagramas opcionales del manual de arquitectura.
- `database/` — notas y visuales de referencia del manual de base de datos.

## Regla

Solo colocar aquí capturas finales. Mientras no existan imágenes reales, mantener notas marcadoras en Markdown.
